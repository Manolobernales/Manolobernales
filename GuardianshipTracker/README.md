# Guardianship Tracker

Esta app de ejemplo para Android permite llevar un registro sencillo de los pagos mensuales de los miembros de una asociación por concepto de guardianía. Está construida con Kotlin y Jetpack Compose e incluye una base de datos local usando Room.

## Cómo compilar
1. Asegúrate de tener instalado Android Studio con un SDK reciente.
2. Clona este repositorio y abre la carpeta `GuardianshipTracker` con Android Studio.
3. Ejecuta el gradle wrapper (`./gradlew`) para descargar las dependencias.
4. Compila y ejecuta la aplicación en un emulador o dispositivo Android.

Debido a que este entorno no dispone de acceso a internet, no se han generado los archivos del Gradle Wrapper. Al abrir el proyecto con Android Studio se generarán automáticamente.
